예측값 하나보다 구간이 더 정직할 때 — 컨포멀 예측 입문

머신러닝 모델의 예측과 함께 “이 답을 어느 정도 믿어도 되는가?”를 데이터로 표현하는 방법을 기초부터 정리했습니다.

점 하나로는 부족할 때

회귀 모델은 보통 하나의 숫자를 출력합니다. 하지만 실제 사용자는 예측값만큼이나 오차의 크기를 알고 싶습니다. 컨포멀 예측은 모델을 바꾸는 기법이 아니라 calibration 데이터에서 관측된 오차로 예측 구간을 만드는 절차입니다.

점 예측: ŷ = 42
컨포멀 구간: ŷ ± q = [35, 49]

Coverage란?

신뢰수준 90%는 반복해서 구간을 만들었을 때 실제 값이 그 안에 들어가는 비율이 약 90%가 되도록 설계한다는 뜻입니다. 개별 샘플의 확률이나 인과관계를 보장하는 지표는 아닙니다.

Split Conformal 5단계

  1. train과 calibration set을 나눕니다.
  2. train set으로 모델을 학습합니다.
  3. calibration set의 절댓값 오차를 계산합니다.
  4. 오차의 상위 분위수 q를 구합니다.
  5. 새 예측에 [ŷ − q, ŷ + q]를 붙입니다.
model.fit(X_train, y_train); errors = abs(y_cal - model.predict(X_cal)); q = np.quantile(errors, 0.9, method="higher"); interval = (pred - q, pred + q)

실무에서 주의할 점

  • 데이터 분포가 바뀌면 coverage 보장이 약해질 수 있습니다.
  • 시간 순서가 있는 데이터는 무작위 분할을 피해야 합니다.
  • 구간이 넓다는 것은 불확실성이 크다는 뜻입니다.

마무리

컨포멀 예측은 기존 모델 위에 calibration 절차를 추가해 예측값과 불확실성을 함께 전달하는 방법입니다.
