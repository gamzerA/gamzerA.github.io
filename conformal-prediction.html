예측값 하나보다 구간이 더 정직할 때 — 컨포멀 예측을 직접 이해하기

모델의 예측과 함께 불확실성을 전달하는 방법을 기초부터 정리했습니다.

왜 예측 구간이 필요한가

점 예측만으로는 재고와 리스크를 결정하기 어렵습니다. 컨포멀 예측은 모델을 교체하지 않고 calibration 데이터의 오차로 예측 구간을 만드는 절차입니다.

기본 용어

  • Coverage: 실제 값이 구간 안에 포함되는 비율
  • Miscoverage α: 구간 밖으로 벗어나는 허용 비율
  • Interval width: 예측 구간의 너비
  • Calibration set: 모델의 오차를 측정하는 데이터
예측 구간 = [ ŷ − q1−α, ŷ + q1−α ]

Split Conformal의 흐름

① train / calibration 분할 → ② train으로 모델 학습 → ③ calibration 오차 계산 → ④ 오차 분위수 q 선택 → ⑤ 새 예측에 [ŷ−q, ŷ+q] 적용

Calibration 데이터를 학습에 다시 사용하면 오차가 실제보다 작아질 수 있습니다. 모델이 본 데이터와 오차를 측정할 데이터를 분리해야 합니다.

최소 구현

model.fit(X_fit, y_fit); cal_pred = model.predict(X_cal); scores = np.abs(y_cal - cal_pred); q = np.quantile(scores, 0.9, method="higher"); pred = model.predict(X_new); interval = (pred - q, pred + q)

Coverage와 구간 너비 확인

covered = (y_test >= lower) & (y_test <= upper); coverage = covered.mean(); width = (upper - lower).mean()

Coverage만 높이면 구간을 지나치게 넓게 만들 수 있으므로 coverage와 평균 width를 함께 비교해야 합니다.

회귀와 분류

회귀는 숫자 구간을 출력하고, 분류는 가능한 라벨의 집합을 출력합니다. “고양이” 하나 대신 {고양이, 여우}처럼 후보 집합을 반환하는 방식입니다.

흔한 실수와 한계

  1. 전체 데이터에 전처리를 먼저 적용해 calibration 정보가 새는 경우
  2. 시간 순서를 무시하고 무작위 분할하는 경우
  3. calibration set이 너무 작아 분위수 추정이 불안정한 경우
  4. 운영 데이터의 분포가 바뀌어도 과거 coverage가 유지된다고 가정하는 경우

기본 보장은 교환가능성 아래의 평균적인 marginal coverage입니다. 모든 개별 샘플에서 같은 확률로 맞는다는 뜻도, 인과관계나 편향을 해결한다는 뜻도 아닙니다.

마무리

컨포멀 예측은 모델이 모르는 부분을 숨기지 않고 표현하는 방법입니다. 신뢰수준을 80%, 90%, 95%로 바꿔 coverage와 구간 너비를 비교하면 데이터의 불확실성을 더 잘 이해할 수 있습니다.
